# 半導体物理 学習アプリ

半導体物理（結晶・量子力学の基礎）を学ぶためのブラウザ学習アプリです。ビルド不要の HTML / CSS / JavaScript のみで作られており、ブラウザで開くだけで動作します。

## 概要

大学の授業で配布された資料（結晶構造、量子力学概要、問題集）の内容をもとに、以下の4つの機能を1つのアプリにまとめています。

- **用語辞典**：授業に登場する専門用語を検索・カテゴリ絞り込みしながら確認できます。図解や数式（KaTeXで表示）、資料のページ番号つきです。
- **結晶3Dビューワー**：単純立方・体心立方・面心立方・六方最密・ダイヤモンド構造・NaCl構造を3Dで回転させて観察できます。ミラー指数 (h k l) を入力するとその結晶面がハイライト表示されます。刃状転位・らせん転位のモデルもスライダーで動かして観察できます。
- **量子力学シミュレーション**：無限/有限の井戸型ポテンシャル（トンネル的浸透）、ボーアの原子モデル、不確定性原理、物質波（波束）をスライダーで条件を変えながら可視化します。
- **理解確認クイズ**：問題集（結晶1〜6・量子力学1〜5）をベースにした選択式・数値計算式の問題で理解度を確認できます。

## 使い方

### オンラインで使う
上記のURLをブラウザで開くだけです。

### ローカルで使う（オフライン）
1. このリポジトリをクローンまたはダウンロードする
   ```
   git clone https://github.com/1125kojima-prog/handoutai.git
   ```
2. `index.html` をブラウザで直接開く（ダブルクリックでOK。サーバーやビルドは不要です）

画面上部のタブで「用語辞典」「結晶3Dビューワー」「量子力学シミュレーション」「理解確認クイズ」を切り替えられます。結晶3Dビューワーはドラッグで回転、スクロール（ピンチ）で拡大縮小できます。

## 使用した技術スタック

- **HTML / CSS / JavaScript（Vanilla, ESモジュール非使用）**：ビルドツールやフレームワークを使わず、`<script>` タグの読み込みのみで動作します。
- **[Three.js](https://threejs.org/)（r0.140, UMD版 + OrbitControls）**：結晶構造の3D描画・回転操作。
- **[KaTeX](https://katex.org/)（v0.16.9）**：用語辞典内の数式表示。
- **Canvas 2D API**：量子力学シミュレーションの波形・グラフ描画（追加ライブラリなし）。
- Three.js と KaTeX は `lib/` 以下にローカル同梱しており、インターネット接続なしでも全機能が動作します（初回ダウンロード後はオフライン対応）。

## 注意点

- このリポジトリには、元になった授業資料のPDF（結晶・量子力学・問題集）は**含まれていません**（著作物のため `.gitignore` で除外）。アプリ内のデータは、それらの資料に登場する用語・構造・題材を要約・再構成したものです。
- 教育用の可視化を優先しているため、一部のシミュレーション（有限井戸型ポテンシャルの数値解、物質波の波束表示など）は計算の見通しを良くするための簡略化・近似や、表示用のスケール調整を行っています。定量的な研究・設計目的での利用は想定していません。
- 結晶3Dビューワーの描画には WebGL が必要です。最新版の Chrome / Edge / Firefox など、WebGLに対応したブラウザでの利用を推奨します。
- クイズの問題は資料の例題・問題を参考にした自己完結型の設問であり、元の問題文そのものの再掲ではありません。
